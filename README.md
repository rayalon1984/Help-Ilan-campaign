## 📋 לפני ההשקה - חובה לעדכן!

### 1. העלאת תמונת פרופיל

העלה את תמונת הפרופיל של אילן לתיקייה `images/` ושנה שם ל-`profile.jpg`

```bash
# העלה את התמונה לתיקייה images/
cp path/to/ilan-photo.jpg images/profile.jpg
```

### 2. עדכון פרטי בנק

ערוך את קובץ `index.html` ועדכן את השורות הבאות (בערך שורות 347-349):

```html
<span class="bank-detail-value" id="bankName">[שם הבנק שלך]</span>
<span class="bank-detail-value" id="branchNumber">[מספר סניף]</span>
<span class="bank-detail-value" id="accountNumber">[מספר חשבון]</span>
```

**החלף את הטקסט בסוגריים המרובעים בפרטים האמיתיים!**

## 🔄 עדכון התקדמות הקמפיין

יש שתי דרכים לעדכן את התקדמות התרומות:

### אפשרות 1: דרך קונסול הדפדפן (מומלץ לעדכונים מהירים)

1. פתח את העמוד בדפדפן
2. לחץ `F12` כדי לפתוח את Developer Tools
3. עבור ללשונית **Console**
4. הכנס את הפקודה הבאה (שנה את המספרים לפי הצורך):

```javascript
updateProgress(15000, 25); // 15,000 ₪ מ-25 תורמים
```

**שים ❤️**: העדכון הזה לא ישמר - הוא רק לצפייה זמנית. לעדכון קבוע, השתמש באפשרות 2.

### אפשרות 2: עריכת קובץ HTML (לעדכון קבוע)

ערוך את `index.html` ושנה את השורה האחרונה (שורה 482 בערך):

```javascript
// שנה מזה:
updateProgress(0, 0);

// לזה (לדוגמה):
updateProgress(15000, 25); // 15,000 ₪ מ-25 תורמים
```

אחרי העריכה, עשה commit ו-push לעדכן את העמוד ב-GitHub Pages:

```bash
git add index.html
git commit -m "עדכון התקדמות: 15,000 ₪ מ-25 תורמים"
git push
```
